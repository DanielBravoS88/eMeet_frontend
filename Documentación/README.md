# Documentación del proyecto eMeet Frontend

Este directorio centraliza los entregables documentales solicitados por la pauta académica.

## Estructura sugerida

- `Informe/`: informe principal del proyecto (PDF/DOCX).
- `UML/`: diagramas UML (casos de uso, clases, secuencia, etc.).
- `WireFrame/`: wireframes/prototipos de pantallas.
- `MER/`: modelo entidad-relación y artefactos de base de datos.
- `Gantt/`: planificación temporal del proyecto.
- `QA/`: evidencias de pruebas funcionales/no funcionales y control de calidad.
- `Infraestructura_y_Ambiente_Cloud/`: evidencias IL 2.2 (ambiente de pruebas cloud, stack y backups).

## Formatos aceptados (referencia)

Según la pauta: `xls`, `xlsx`, `ppt`, `pdf`, `doc`, `docx` u otro formato definido por el docente.

## Nota

Este ajuste organiza el repositorio sin tocar código fuente. Los entregables reales deben ser incorporados por el equipo en las carpetas indicadas.

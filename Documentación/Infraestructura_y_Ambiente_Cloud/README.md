# Infraestructura y Ambiente Cloud (IL 2.2)

Esta sección concentra evidencias del ambiente de pruebas en la nube replicando producción.

## Subcarpetas

- `Ambiente_Pruebas_Cloud/`
  - Evidencias de infraestructura cloud (AWS/Azure/GCP): arquitectura, servicios usados, capturas de consola, red, seguridad, despliegue.

- `Stack_Tecnologico_Servidor/`
  - Evidencia de lenguajes, frameworks, librerías, dependencias y versiones instaladas en servidor/entorno de pruebas.

- `Gestion_de_Datos_Backup/`
  - Evidencias del procedimiento de respaldo de datos desde producción hacia pruebas.
  - Incluir frecuencia, pasos, validación de restauración y responsables.

## Recomendación de evidencia mínima

1. Documento de arquitectura del ambiente de pruebas.
2. Capturas de despliegue y configuración base.
3. Inventario de stack/versions.
4. Procedimiento de backup + prueba de restauración.

## 🔍 Cómo revisar los documentos

1. Todos los archivos están en formato **Markdown** (`.md`) y pueden visualizarse directamente en GitHub o en cualquier editor compatible (VS Code, Obsidian, etc.).
2. Los diagramas están escritos en **Mermaid**, un lenguaje de diagramas embebido en Markdown. GitHub los renderiza automáticamente.
3. Cada documento indica claramente qué información es:
   - ✅ **Confirmada**: obtenida directamente del análisis del repositorio.
   - 🔍 **Inferida**: deducida a partir del código y la estructura del proyecto.
   - ⏳ **Pendiente por validar**: requiere acceso al repositorio `eMeet_Backend_Supabase` o al proyecto Supabase para ser completada.

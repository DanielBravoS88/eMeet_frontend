# Producto

Este directorio se incorpora para alinear el repositorio con la pauta académica.

## Ubicación actual del producto frontend

Para evitar riesgos funcionales, el código fuente y configuración del frontend se mantienen en su ubicación actual:

- `app/`
- `src/`
- `public/`
- archivos de configuración (`package.json`, `next.config.mjs`, `tailwind.config.js`, etc.)

## Qué ubicar aquí adicionalmente

- Scripts o artefactos complementarios del producto (si aplica para evaluación).
- Referencias a datos de prueba o recursos de apoyo (sin duplicar código existente).

> Nota: esta mejora es organizativa/documental y no altera lógica de la aplicación.
